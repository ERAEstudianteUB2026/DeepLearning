# Laboratorio RNN 2-2-1 y BPTT

Aplicación Streamlit para recorrer fórmula, sustitución y resultado de cada paso del forward, backward y actualización, y entrenar la misma red visualmente.

Archivos: `streamlit_app.py`, `requirements.txt`.

Para ejecutar: `streamlit run streamlit_app.py`.

Publicación: subir ambos archivos a la raíz del repositorio GitHub y desplegar `streamlit_app.py` desde la rama `main` en Streamlit Community Cloud.
